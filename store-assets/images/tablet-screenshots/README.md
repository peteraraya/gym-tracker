# 📱 Capturas de Pantalla — Tablet (Opcional pero recomendado)

## Especificaciones técnicas
- **Dimensiones:** 1200 × 1920 px o 1920 × 1200 px
- **Formato:** PNG o JPEG (24-bit)
- **Cantidad mínima:** 1 captura
- **Tamaño máximo por archivo:** 8 MB

## Capturas sugeridas
- Dashboard en tablet (layout de dos columnas)
- Entrenamiento en tablet (vista dividida)
- Progreso en tablet (gráficas más grandes)
