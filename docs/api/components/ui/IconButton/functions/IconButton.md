Botón de ícono accesible.

Siempre requiere `aria-label` para que los lectores de pantalla
puedan describir la acción del botón.

Ejemplo:
  <IconButton aria-label="Cerrar modal" onClick={onClose}>
    <X className="w-5 h-5" />
  </IconButton>
