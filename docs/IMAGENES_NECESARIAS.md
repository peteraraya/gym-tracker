## Fuentes sugeridas para descargar:

### Opción 1: MuscleWiki (requiere VPN o proxy si tu red lo bloquea)
URL base: https://cdn.musclewiki.com/media/uploads/videos/branded/
Ejemplo: https://cdn.musclewiki.com/media/uploads/videos/branded/male-barbell-bench-press-front.gif

### Opción 2: Buscar en Google/Giphy/Tenor
Buscar: "[nombre del ejercicio] gif animation"
Ejemplo: "barbell bench press gif animation"

### Opción 3: Usar un proxy/VPN
Si tienes problemas de red para acceder a MuscleWiki, usa un proxy o VPN

### Opción 4: Alternativas gratuitas
- **ExRx.net**: Tiene diagramas e imágenes de ejercicios
- **Strength Level**: Ilustraciones de ejercicios
- **Freepik/Flaticon**: Animaciones SVG (más livianas que GIF)
